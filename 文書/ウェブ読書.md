# Client-side vertical web reader

Open `/?w=https%3A%2F%2Fexample.jp%2F` on the generated site, or use **綴りで読む** on the homepage. The URL can contain its own query string and fragment when encoded with `encodeURIComponent`.

The feature is a separate compiler in `src/読取/`, with a small site entry point in `例/読書.ts`. It does not enlarge `dist/tsuzuri.js`. There is no API, proxy, inference service, server-side computation or generative model.

## Pipeline

1. Validate and canonicalise the source URL. Check IndexedDB before fetching or starting a model worker.
2. Fetch public HTML directly with CORS and omitted credentials, or import a saved HTML file. Decode declared character sets, including Shift JIS. Cap downloaded HTML at 2 MiB.
3. Sanitise with DOMPurify and measure in a script-disabled, same-origin sandbox. Resolve resource URLs against the source. Source CSS and fonts can load in this isolated frame; source JavaScript cannot run. Controls become disabled snapshot controls.
4. Build an intermediate representation from computed styles, owned text, layout boxes, semantic HTML, ARIA roles and document language. Text ownership avoids counting nested paragraphs several times. Native ruby remains intact. `Intl.Segmenter` supplies word and grapheme boundaries with UTF-16 source offsets. Unicode properties classify scripts, without matching site names or CSS classes.
5. Build containment, source-order, alignment, explicit label and bounded spatial-neighbour edges. No site-specific selectors or keyword rules identify layout components.
6. Encode semantic role descriptions and region text using the quantised multilingual MiniLM sentence encoder in a dedicated Web Worker. The model is pinned to `Xenova/paraphrase-multilingual-MiniLM-L12-v2`, revision `2c4055b12046f11709e9df2c122e59ffbdc2f900`. Transformers.js runs ONNX locally through concurrent WebGPU and WASM workers. A shared length-sorted queue preserves output order while workers take more work as they finish. Batch sizes adapt to measured inference time. WASM starts immediately, without waiting for GPU model loading; completion cancels any unnecessary initialisers. Up to three WASM workers are allowed by CPU and memory budgets, with one ONNX thread each so cross-origin isolation is unnecessary. WebGPU uses FP16 when the adapter supports it and FP32 otherwise; WASM uses Q8. Failed GPU batches are returned to the queue for another worker. Web Locks serialise same-backend model initialisation so CPU peers reuse cached weights rather than duplicate cold downloads. Model files download from Hugging Face once and are cached by Transformers.js. Text is never sent to Hugging Face for inference.
7. Combine embedding similarities with declared semantics, geometry, language and link density. Six damped graph passes let neighbouring regions influence each other. These normalised scores and entropy estimates are **not calibrated statistical probabilities**. The graph coefficients and layout objective are explicit engineering policies; they are not a trained webpage-layout model.
8. Preserve the semantic tree, text, ruby and inline links. Emit native vertical Japanese text using Tsuzuri's typography classes, strict browser line breaking and short-number 縦中横. Code, tables, controls and explicit non-Japanese regions stay horizontal. No readings, character compositions, dates or words are invented.
9. Try three global column heights and measure actual browser overflow and sibling collisions. Repair vertically overflowing regions by retaining horizontal presentation. Preserve broad source column proportions where the measured hierarchy supports them; stack these groups on narrow viewports. DOM order remains unchanged.
10. Save the compiled HTML, sanitised original, graph, plans, source fingerprint and model identity. Re-sanitise cached HTML before displaying it.

## Caching

| Layer | Stored information | Reuse |
|---|---|---|
| IndexedDB | Finished page, original snapshot and compiler IR | Immediate repeat opening, without a source fetch or model worker |
| Cache API | Content-addressed 384-dimensional embeddings | Refresh, changed pages, repeated text and new viewport layouts |
| Transformers.js browser cache | Pinned model and tokenizer files | Subsequent local inference without another weight download |

Finished-page keys include engine version, model revision, mixed-precision policy, full source URL including query, exact frame width and height, and semantic/structural mode. Fragments share a layout. The compiled cache keeps at most 24 entries and 32 MiB, with least-recently-used eviction. Embeddings have a separate 2,048-entry bound. Browser storage can still be evicted by the browser or cleared by the user. Storage failure does not prevent reading and is reported in the status.

Repeat opening deliberately uses the saved snapshot. Its date is visible. **更新** fetches and recompiles the latest page, reusing known embeddings. It also remeasures external CSS, which can change independently of HTML. After a day, the UI reminds the reader that an update is available. Resizing uses the stored source and cached embeddings, without another source request. **元の配置** toggles to the sanitised original snapshot.

## Current boundaries

- CORS is a browser restriction. A static website cannot fetch every arbitrary origin, inspect an unrelated iframe or bypass a site's access controls. Sites that do not permit direct fetching require a saved HTML import. An extension would be needed for general access to an already running page.
- This is a reading snapshot, not a replacement runtime for arbitrary web applications. JavaScript-rendered content must already be present in the imported HTML. Forms, editors, embedded frames, scripts and custom application behaviour are not reproduced.
- Inline CSS is observable. External stylesheets can be applied by the browser, but inaccessible stylesheet rules are not a complete export of the source's font assets or design system. The output rebuilds layout and preserves measured font families, sizes, colours and broad grouping; it does not promise pixel fidelity.
- GPU and CPU embeddings use the same semantic space but different numerical precision. Cache identities include the mixed-precision policy. Initial runs are not promised to be bit-identical across hardware.
- The pretrained model understands multilingual sentence similarity. It was not trained here on labelled Japanese website layouts. Semantic anchors plus structured inference are an implemented starting point, not evidence of universal understanding. A diverse, human-reviewed Japanese benchmark and a trained relational layout model remain further work.
- Semantic inference is bounded to the 384 largest eligible text regions, using extractive beginning/middle/end windows for long text. The remaining regions still receive structural and graph analysis. The full source text is retained. Source measurement is capped at 12,000 elements.
- If model loading or inference fails, the UI reports structural-only analysis. The semantic checkbox allows that mode explicitly. An explicit refresh can retry the model. Downloading and inference can take time on the first visit.
- A saved page can be reopened without fetching its source. Full offline launch of the application shell and offline copies of all remote images/fonts are not implemented.

## Verification

```sh
bun install
bun run build
bunx playwright install chromium
bun run test:browser
```

Independent library bundles, site bundles and static-asset copies are built concurrently. DOM measurement and dependent layout validation remain ordered because they rely on the browser layout engine.

The unit suite covers mixed-device work sharing, adaptive batch bounds, GPU failure recovery, cancellation, slow initialisation, URL parsing, cache identities, lossless mixed-script segmentation, deterministic graph inference and protected regions. The reader browser suite checks native ruby, numeric runs, hidden content, source-script isolation, original/vertical toggling, repeat-visit cache hits, refresh without repeated embedding inference responsive recompilation, HTML import after a fetch failure and storage-denied fallback. It uses a deterministic worker fixture so CI does not depend on a large external model download. This suite does not measure semantic accuracy on unfamiliar websites.

References: [Transformers.js model usage](https://huggingface.co/Xenova/paraphrase-multilingual-MiniLM-L12-v2), [Transformers.js environment and browser caching](https://huggingface.co/docs/transformers.js/api/env), [Fetch and CORS](https://fetch.spec.whatwg.org/), [Japanese Text Layout Requirements](https://www.w3.org/International/jlreq/).

## Source-tab bookmarklet

When direct fetching fails, drag **綴りで読む** from the reader toolbar into the browser bookmark bar. Open the source website and activate that bookmark. It opens Tsuzuri and transfers the currently rendered DOM directly between the two tabs, without a proxy, file download or another source fetch. The receiver checks the opener window, exact source origin, source URL and a fresh random token, then applies the normal size limits and sanitisation. The bookmarklet must be explicitly activated on the source site. Popup blocking, restrictive source CSP and cross-origin opener isolation can prevent this bridge; HTML import remains available in those cases.
