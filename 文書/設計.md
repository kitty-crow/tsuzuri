# 設計の約束

## 配布物

各配布ファイルは単独で読み込み可能な即時実行形式です。
内部の共通処理はそれぞれに内包し、閲覧時の外部依存物を必要としません。
付随する様式ファイルは、同じフォルダーから自動で読み込みます。

統合版は全機能を含みます。どちらの版も既存の本文全体を
意図せず縦書きに変えず、専用の要素で指定された部分だけを扱います。
指定した要素では縦書きが既定です。

## 原稿

使用するのは厳格な型付きの原稿です。条件分岐の入れ子、
曖昧な型、型検査の無効化、通常の JavaScript 原稿は検査で拒否します。

## DOMと書体

描画開始時に対象要素を意味のある標準要素に置換します。
後から挿入した対象要素も監視し、再初期化の明示的な呼出しは不要です。

振仮名は `ruby` および `rt` に置換します。
合成漢字には元の表意文字記述を選択可能な状態で残し、
書体によらない構造化描画を装飾層に分離します。
合成文字の読みによる曖昧さは明示的に解消できます。

## 紹介ページと配布ライブラリーの分離

紹介ページの原稿は `例/` に置き、構築時だけ
`vendor/website/src/reactHelpers.tsx` を使用します。
React は紹介ページの生成環境に限られ、配布物には含まれません。

## 未対応事項

旧暦の全面的な天文換算、特殊な表意文字記述演算子、
多様な禁則処理の独自実装は将来の拡張領域です。
これらを既に実装したものとして扱わないことを原則とします。
