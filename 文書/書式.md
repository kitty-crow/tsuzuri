# 要素と属性

## 基本

`<tsuzuri>` と `<t-綴>` は、内容を綴りで処理する領域を指定します。縦書きは既定値であり、処理領域そのものの意味ではありません。日本語の要素名には HTML の構文上必要な `t-` を付け、ローマ字の要素名には付けません。

| 働き | 日本語 | ローマ字 | 属性 |
|---|---|---|---|
| 処理領域 | `<t-綴>` | `<tsuzuri>` | `縦`・`横` ／ `vertical`・`horizontal` |
| 縦書き領域 | `<t-縦>` | `<tategaki>` | なし |
| 横書き領域 | `<t-横>` | `<yokogaki>` | なし |
| 縦中横 | `<t-縦中横>` | `<tcy>` | なし |
| 振仮名 | `<t-振り>` | `<furigana>` | `読み` ／ `reading` |
| 漢字・合成漢字 | `<t-漢字>` | `<kanji>` | `振り`・`縦`・`横` ／ `reading`・`vertical`・`horizontal` |
| 組版 | `<t-組版>` | `<kumihan>` | なし |
| 漢数字 | `<t-漢数字>` | `<kansuji>` | `値`・`形式` ／ `value`・`style` |
| 暦 | `<t-暦>` | `<koyomi>` | `日付`・`暦` ／ `date`・`calendar` |

指定した方向はその要素の内側にだけ適用され、閉じると親要素の方向に戻ります。日本語とローマ字の記法は一つの処理領域内で混在できます。

```html
<t-綴 横>
  横書きの文章です。
  <t-縦>この部分は縦書きです。</t-縦>
  続きは横書きに戻ります。
  <t-縦中横>2026</t-縦中横>
</t-綴>
```

## 振仮名

読みだけを指定した `<kanji>` と `<t-漢字>` は文字を合成せず、振仮名を付けます。専用の振仮名要素と同じ結果になります。

```html
<tsuzuri>
  <furigana reading="ことば">言葉</furigana>
  <kanji reading="ことば">言葉</kanji>
</tsuzuri>
```

```html
<t-綴>
  <t-振り 読み="ことば">言葉</t-振り>
  <t-漢字 振り="ことば">言葉</t-漢字>
</t-綴>
```

## 合成漢字

`横` ／ `horizontal` は左右（`⿰`）、`縦` ／ `vertical` は上下（`⿱`）に二つの文字を組み合わせます。合成方向を指定しない単なる二文字は合成しません。ただし表意文字記述の `⿰` と `⿱` は引き続き認識します。

```html
<t-綴>
  <t-漢字 横 振り="つづり">綴り</t-漢字>
  <t-漢字 縦 振り="にほん">日本</t-漢字>
</t-綴>
```

```html
<tsuzuri>
  <kanji horizontal reading="つづり">綴り</kanji>
  <kanji vertical reading="にほん">日本</kanji>
</tsuzuri>
```

複雑な文字には入れ子を使います。入れ子の途中の字下げ・改行は部品として数えません。

```html
<t-綴>
  <t-漢字 縦>
    <t-漢字 横>日本</t-漢字>
    <t-漢字 横>綴り</t-漢字>
  </t-漢字>
</t-綴>
```

```html
<tsuzuri>
  <kanji vertical>
    <kanji horizontal>日本</kanji>
    <kanji horizontal>綴り</kanji>
  </kanji>
</tsuzuri>
```

いずれも次の表意文字記述と同じ構造です。

```html
<kanji>⿱⿰日本⿰綴り</kanji>
```

描画される文字と、元になった表意文字記述は別の層に置きます。原文は選択・複写可能です。文字の見た目は書体や閲覧環境によって多少異なります。

## 漢数字

`style` には `digits`（各桁）と `daiji`（大字）を指定できます。
省略時は位取り表記です。日本語の属性は `値` と `形式` を用います。

```html
<t-綴>
  <t-漢数字 値="2026"></t-漢数字>
  <t-漢数字 値="18" 形式="大字"></t-漢数字>
</t-綴>
<kansuji value="2026"></kansuji>
<kansuji value="2026" style="digits"></kansuji>
<kansuji value="18" style="daiji"></kansuji>
```

## 暦

```html
<t-綴>
  <t-暦 日付="2026-10-28"></t-暦>
  <t-暦 日付="2026-10-28" 暦="旧暦"></t-暦>
</t-綴>
<koyomi date="2026-10-28"></koyomi>
<koyomi date="2026-10-28" calendar="kyureki"></koyomi>
```

旧暦の換算は限定的です。正確さを保証できない期間では、誤った換算値を作らず、
指定された予備の文字列または入力された日付をそのまま表示します。


## 合成字形の描画方法

元の実演資料と同じ書体を組み込んでいます。次の四つは専用の合成字形を用い、
単に各部品の文字を縮小して並べるのではなく、元の筆画構成を保持した意匠で表示します。

- `⿱日本`
- `⿰日本`
- `⿱⿰日本語`
- `⿱⿰日本⿰語学`

上記以外の合成文字には、文字の輪郭を縦横に伸縮する描画を使います。
専用字形と同じ筆画の接合まで再現できるものではありません。

実演書体は、元の資料において「Noto Serif CJK の字形から作成」と明記され、
SIL オープンフォントライセンス 1.1 の対象とされています。
利用する際は書体の使用条件を確認してください。

## 江戸時代の暦の例

原稿には暦年の日付を直接書かず、グレゴリオ暦の `YYYY-MM-DD` を指定します。
`calendar="kyureki"` で検証済みの寛政暦に換算し、`eto` で干支年を添えます。
同じ年を繰り返す場合は `year="same"` を指定できます。

```html
<koyomi date="1809-12-22" calendar="kyureki" eto></koyomi>
<koyomi date="1811-05-24" calendar="kyureki" eto></koyomi>
<koyomi date="1814-10-10" calendar="kyureki" year="same" day-style="abbreviated"></koyomi>
```

それぞれ「文化六年己巳　霜月十六日」「文化八年辛未　卯月三日」
「同年　葉月廿七日」と表示します。年の省略は利用者が明示的に指定します。

旧暦の大の月・小の月は年ごとに異なり、閏月もあります。
未確認の月には換算値を捏造せず、元の暦日または予備の文字列を表示します。

資料：
- [国立天文台：日本暦日データベース](https://eco.mtk.nao.ac.jp/cgi-bin/koyomi/caldb.cgi)
- [国立国会図書館：大小暦](https://www.ndl.go.jp/koyomi/chapter2/s1.html)

### 最終行の孤立防止

`綴り` と単独版 `縦書`、`組版` は、日本語の文章の末尾にある三字をひとまとまりとして扱います。縦書きの最終列へ一字だけが押し出されることを防ぎます。対象は `p`、`li`、`blockquote`、`kumihan` です。振仮名付きの文字と合成漢字は一字のまとまりとして扱い、内部を分割しません。

末尾に `<br>` で明示した改行がある場合は、その改行より後ろだけを対象とします。短すぎる文章は、そのまま表示します。表示の大きさや書体が変わっても、末尾のまとまりは維持されます。本文を動的に追加したときも自動で再処理します。

これは通常の日本語禁則処理とは別の保護であり、ブラウザーが対応する範囲の `line-break: strict` も併用します。
