# 要素と属性

## 基本

| 要素 | 役割 | 属性 |
|---|---|---|
| `<tsuzuri>` | 縦書き既定の描画領域 | `direction="horizontal"` または `horizontal` |
| `<jp-tategaki>` | 明示的な縦書き | なし |
| `<jp-yokogaki>` | 明示的な横書き | なし |
| `<jp-tcy>` | 縦中横 | なし |
| `<jp-furigana>` | 振仮名 | `reading` または `rt` |
| `<jp-kanji>` | 合成漢字 | `reading`、`alignment` |
| `<jp-kumihan>` | 日本語組版 | なし |
| `<jp-kansuji>` | 漢数字 | `value`、`style` |
| `<jp-koyomi>` | 暦の表記 | `date`、`calendar` |

## 合成漢字

構造を表す `⿰` と `⿱` は、それぞれ左右と上下の組合せを示します。

```html
<jp-kanji reading="にほん">⿱日本</jp-kanji>
<jp-kanji reading="にほんごがく">⿱⿰日本⿰語学</jp-kanji>
```

要素の入れ子でも組み立てられます。

```html
<jp-kanji alignment="vertical" reading="にほん">
  <jp-kanji>日</jp-kanji>
  <jp-kanji>本</jp-kanji>
</jp-kanji>
```

描画される文字と、その元になった表意文字記述は別の層に置かれます。
読者が選択する対象は元の記述です。見た目は書体や閲覧環境によって多少変わります。

## 漢数字

`style` には `digits`（各桁）と `daiji`（大字）を指定できます。
省略時は位取り表記です。

```html
<jp-kansuji value="2026"></jp-kansuji>
<jp-kansuji value="2026" style="digits"></jp-kansuji>
<jp-kansuji value="18" style="daiji"></jp-kansuji>
```

## 暦

```html
<jp-koyomi date="2026-10-28"></jp-koyomi>
<jp-koyomi date="2026-10-28" calendar="kyureki"></jp-koyomi>
```

旧暦の換算は限定的です。正確さを保証できない期間では、誤った換算値を作らず、
指定された予備の文字列または入力された日付をそのまま表示します。


## 合成字形の描画方法

元の実演資料と同じ書体を組み込んでいます。次の四つは専用の合成字形を用い、
単に各部品の文字を縮小して並べるのではなく、元の筆画構成を保持した意匠で表示します。

- `⿱日本`
- `⿰日本`
- `⿱⿰日本語`
- `⿱⿰日本⿰語学`

上記以外の合成文字には、文字の輪郭を縦横に伸縮する描画を使います。
専用字形と同じ筆画の接合まで再現できるものではありません。

実演書体は、元の資料において「Noto Serif CJK の字形から作成」と明記され、
SIL オープンフォントライセンス 1.1 の対象とされています。
利用する際は書体の使用条件を確認してください。
