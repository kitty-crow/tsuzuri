# 綴りで読む：ブラウザー拡張機能

Brave・Chrome向けの試験版です。版番号は0.1.0です。

## 導入

1. 配布ZIPを解凍し、使用中はフォルダーを残します。
2. Braveでは `brave://extensions`、Chromeでは `chrome://extensions` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` のあるフォルダーを選びます。
5. 拡張機能一覧で「綴りで読む」をツールバーに固定します。
6. 読みたいページを開き、拡張機能のアイコンを押します。

表示中のページを取得し、別のタブに縦書きの読書画面を開きます。「更新」は元のタブを取り込み直します。「元の配置」で取得時の配置に切り替えます。

初回は意味解析モデルを取得します。解析はブラウザー内で実行し、モデル・意味ベクトル・組版結果を保存します。処理中は工程、進捗、残り時間の目安を表示します。

## 権限と制限

`activeTab`・`scripting`・`storage` を使用します。ページへのアクセスはアイコンを押したタブに限り、常時のホスト権限はモデル配信元のHugging Faceに限定しています。

取得したページのスクリプトと操作部は読書画面では動作しません。ブラウザー内部のページ、別オリジンの埋込みフレーム、閉じたシャドウDOM、キャンバス上の文字は対象外です。CSSの保持と配置の推定には未対応の部分があります。

直近2件の取得内容をセッション内に保持します。組版結果の保存上限は24件・32 MiBです。自動更新には対応していません。更新版は同じフォルダーに展開し、拡張機能の管理画面で再読み込みしてください。

## 構築

```sh
bun install
bun run build
bun run test:extension
```

出力先は `extension-dist/` です。配布時は、このディレクトリーの内容をZIPにまとめます。ライブラリー単体は `bun run build:lib` で構築します。
