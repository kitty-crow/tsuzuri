# Tsuzuri Reader for Brave / Chrome

This is an unpacked Manifest V3 extension, version 0.1.0.

## Install

1. Extract the ZIP into a folder you will keep.
2. Open `brave://extensions` in Brave, or `chrome://extensions` in Chrome.
3. Enable **Developer mode** at the top right.
4. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
5. Pin **綴りで読む** using the browser's Extensions menu.
6. Open a Japanese website and click the extension's toolbar icon.

The extension captures the DOM and computed layout of the page you already have open. It opens a separate vertical reader tab. No bookmarklet, source fetch, opener or cross-origin tab messaging is needed. Existing scripts and controls on the source tab are left in place. The reading copy does not execute source scripts.

Japanese headings, controls, instructions and progress are vertical. The original snapshot is visible while semantic analysis runs. The progress display reports model loading, completed analysis regions and an approximate ETA for the current phase. Models, embeddings and finished layouts are cached locally. First use downloads model data; inference runs locally through WebGPU and WASM. No page text is sent to an inference server.

Click **更新** in the extension reader to recapture its original tab. Click the extension again on another source page to open another reading copy. Two recent source snapshots are held in extension session storage; finished reading views have the existing bounded persistent cache. The captured source DOM and layout are used to detect changes before reusing a finished view.

The extension uses `activeTab`, `scripting` and `storage`. Website access is granted temporarily when you click the icon. Permanent host permissions are limited to the model data hosts. All executable code, workers and WebAssembly runtime files are packaged locally. Model weights and tokenizer data are downloaded from Hugging Face.

Browser-internal pages, extension stores and some protected documents cannot be captured. The main document is analysed; cross-origin frames, closed shadow roots and canvas text are not extracted. Layout quality remains experimental. This build has not been submitted to the Chrome Web Store and does not update automatically: replace its folder and press **Reload** on the Extensions page when installing an update.

## Build and test

```sh
bun install
bun run build
bun run test:extension
```

The output is `extension-dist/`. Package that directory's contents so `manifest.json` is at the ZIP root.
